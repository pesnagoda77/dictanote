# DictaNote — Аналитика рынка: Следующая ниша

## Методология
- Ищем приложения с отзывами 0-2 звезды
- Причины: бесплатные убогие, платные дорогие
- Цель: сделать лучше, дешевле, с монетизацией

---

## Категория 1: AI-заметки с голосовым вводом

**Конкуренты:**
- Otter.ai — $10/мес, облачный
- Notion AI — $10/мес, сложный
- Google Keep — бесплатный, убогий AI

**Проблемы в отзывах:**
- «Otter дорогой, а бесплатный лимит 30 минут»
- «Notion сложный, не для быстрых заметок»
- «Keep не понимает русский, нет офлайна»

**Возможность:** DictaNote уже делает это! Русский, офлайн, дешево.

---

## Категория 2: Скриншот-органайзер / Screenshot management

**Конкуренты:**
- Shottr (Mac) — $8, нет Android
- CleanShot X — $29, только Mac
- Android Gallery — убогий, нет поиска

**Проблемы в отзывах:**
- «На телефоне 5000 скриншотов, найти невозможно»
- «Галерея не ищет по тексту на скриншоте»
- «Нет OCR для скриншотов»

**Возможность:** Приложение для организации скриншотов с OCR + поиск по тексту на изображении.

---

## Категория 3: Локальный переводчик / Offline translator

**Конкуренты:**
- Google Translate — требует интернет
- DeepL — платный, облачный
- Apple Translate — только iOS, не русский

**Проблемы в отзывах:**
- «В поездке нет интернета, переводчик не работает»
- «Google Translate требует VPN в некоторых странах»
- «Нет офлайн-перевода для редких языков»

**Возможность:** Офлайн-переводчик с локальными моделями (как VOSK, но для перевода).

---

## Категория 4: Умный диктофон для врачей / юристов

**Конкуренты:**
- Dragon Medical — $500+/год
- Philips SpeechLive — $20/мес
- Обычные диктофоны — нет транскрипции

**Проблемы в отзывах:**
- «Dragon Medical дорогой, сложный»
- «Обычный диктофон — потом час transcribe»
- «Нет специализированной терминологии»

**Возможность:** DictaNote PRO для врачей/юристов с медицинской/юридической терминологией.

---

## Категория 5: Автоматические заметки с встреч

**Конкуренты:**
- Fireflies.ai — $10/мес, облачный
- Fathom — $15/мес, только Zoom
- Otter — $10/мес

**Проблемы в отзывах:**
- «Fireflies требует доступ к календарю, страшно»
- «Fathom только Zoom, не работает с Meet»
- «Все облачные — конфиденциальность нулевая»

**Возможность:** Локальное приложение для записи встреч + транскрипция + саммари. Без облака.

## Топ-3 рекомендации

### 1. Скриншот-органайзер с OCR (Screenshot Manager)
**Почему:**
- Огромная боль (5000+ скриншотов на телефоне)
- Нет хорошего решения на Android
- OCR + поиск по тексту = уникальная фича
- Монетизация: разовая покупка PRO ($3-5)

**Сложность:** Средняя (Flutter + MLKit OCR)
**Время:** 2-3 недели

### 2. Офлайн-переводчик (Offline Translator)
**Почему:**
- Реальная боль в путешествиях
- Нет хорошего офлайн-решения
- Модели перевода существуют (Argos Translate, LibreTranslate)
- Монетизация: подписка на языковые пакеты

**Сложность:** Высокая (нужны модели перевода)
**Время:** 1-2 месяца

### 3. DictaNote PRO для профессий (Medical/Legal)
**Почему:**
- DictaNote уже есть
- Добавить специализированные модели VOSK
- Монетизация: подписка на терминологию
- B2B рынок (врачи, юристы)

**Сложность:** Низкая (на базе DictaNote)
**Время:** 2-3 недели
